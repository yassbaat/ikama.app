Documentation

GET /api/countries

List all countries

Get a list of all 159 supported countries and their mosque counts.

curl .../api/countries
GET /api/mosques/[country_code]

Get mosques by country

Fetch all mosques for a specific country using its 2-letter ISO code. Support search via ?q=paris.

curl .../api/mosques/FR?q=massy
GET /api/prayer-times/[slug]

Get prayer times

Get the full schedule (iqama & adhan) for a specific mosque by its slug.

curl .../api/prayer-times/mosquee-al-fatiha-massy

Common Questions

Is this the official Mawaqit API?

No. This is an open-source scraper that makes the public data from Mawaqit accessible to developers. We are not affiliated with them.

Is it free?

Yes, 100% free and open source. You can host it yourself or use our public instance.

What about rate limits?

We cache responses aggressively on the Edge. For personal projects, you won't hit any limits. For commercial use, please deploy your own instance.
